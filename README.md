# Shipment Booking and Tracking Platform

A full-stack learning project built using Java, Spring Boot, Angular, PostgreSQL, and Apache Kafka.

## Technology Stack

- Backend: Java 21, Spring Boot, Maven
- Frontend: Angular, TypeScript
- Database: PostgreSQL
- Messaging: Apache Kafka
- Version Control: Git and GitHub
- Development Environment: Windows, WSL 2 Ubuntu, VS Code

## Planned Microservices

1. Booking Service
2. Route Service
3. Pricing Service
4. Tracking Service
5. Notification Service
6. API Gateway (later)

## Architecture

- REST APIs for synchronous communication
- Kafka events for asynchronous communication
- Maven multi-module backend
- Angular frontend in the same repository

## Development Roadmap
